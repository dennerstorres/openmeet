# ADR 0005 — CSP do desktop e várias instâncias
Status: Accepted. Data: 2026-10-18.

Decisão: a CSP distribuída usa `connect-src` com `https:` e `wss:`, mais HTTP e WS só em loopback. O domínio de um servidor de teste não entra na config versionada.

Contexto: o ADR 0003 deixa o usuário escolher o servidor. A CSP do Tauri é fixada no build, então não dá para listar cada instância. A alternativa de fazer o REST no Rust e deixar o LiveKit no WebView não fecha o problema: a mídia continuaria precisando de `wss:` aberto.

Consequência: o WebView pode abrir conexão com qualquer host HTTPS ou WSS. O cliente só envia senha e token para a origem confirmada em `GET /api/v1/instance`, mas a CSP não reforça esse pin. Um script injetado na página poderia falar com outro host. O MVP não renderiza conteúdo remoto.

HTTP público continua fora da CSP. Loopback fica liberado para a API e o LiveKit locais.
