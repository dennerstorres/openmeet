# F12-07 — prova do cliente web

Roteiro humano do G12 (ADR 0014). Nada aqui vira PASS por inspeção de código.

## Antes
- A instância precisa estar no commit da F12-06 ou depois. A imagem da API gera o `dist-web` no build; um redeploy basta.
- `LIVEKIT_URL` da instância em `wss://`. A CSP da página só abre esse domínio.
- Dois PCs, de preferência em redes diferentes. Em cada um: Chrome, Edge e Firefox atuais.
- Abrir `https://{API_DOMAIN}/` e anotar navegador e versão (o painel de dispositivos mostra, por exemplo, `edge 141`).
