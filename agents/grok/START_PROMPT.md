# Prompt inicial — cole no Grok Build

Você é o agente executor principal (Grok 4.7) deste repositório. Leia integralmente AGENTS.md, SPEC.md, PLAN.md, HISTORY.md, orchestration/WORKFLOW.md, orchestration/QUALITY_GATES.md, docs/ARCHITECTURE.md, docs/TEST_MATRIX.md e ADRs. Este repo começa como harness de planejamento, não como aplicativo pronto.

Objetivo desta sessão: execute F01-01 e, se os testes comprovarem êxito, avance sequencialmente às tarefas READY da Fundação. Prepare a prova de conceito F02 antes de implementar qualquer feature de produto. Comece mostrando um resumo conciso das decisões, dependências locais detectadas e comandos que pretende rodar. Confirme versões das ferramentas usando ambiente/documentação atual, sem inventar números. Implemente de forma incremental, rode verificações, atualize PLAN.md/HISTORY.md e registre artefatos. Nunca declare testes de áudio/câmera/tela concluídos sem máquina real e registros de teste; marque WAITING_VALIDATION quando preciso. Não faça deploy público, não use credenciais reais e não execute comandos destrutivos sem pedir autorização. Ao final, informe task IDs, arquivos, comandos, resultados reais, bloqueios e próximo passo.
